# PONDEURMATCH

Banque de matchs de Génie en herbe pour interclasse scolaire.

- 30 matchs
- 3 niveaux
- 96 questions par match
- format Q puis R
- environ 70 % de réponses en noms propres
- aucune répétition ni quasi-doublon
- réponses courtes et arbitrables
- véracité prioritaire

Les Manchettes peuvent porter sur des données actuelles et doivent alors comporter une date de référence dans la question.

La rubrique **Monde contemporain** couvre l'ensemble de l'époque contemporaine et n'est pas limitée aux actualités récentes.
